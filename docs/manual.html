1. 基本の流れ

  1. ファイル → 開く（Ctrl+O）で対象データ（savedata.json または world_data.json）を選びます。 JSON ファイルをウィンドウへドラッグ＆ドロップしても開けます。2回目以降はファイル → 最近開いたファイルからも選べます。v9.2
  2. 上部のタブ（プレイヤー／ワールド／ゲーム変数）を切り替えて編集します。
  3. 入力欄の値はフォーカスが外れた時点（別の欄をクリック等）で反映されます。
  4. ファイル → 上書き保存（Ctrl+S）で書き戻します。保存結果は下部のステータスバーに表示されます。
保存していない変更がある状態で別のファイルを開いたりツールを終了しようとすると、保存するかどうかの確認が表示されます。v9.2
player_data や game_variables を含まないファイル（world_data.json など）も開けます。該当タブには「ありません」と表示されます。
保存するとファイルが上書きされます。初回は必ずコピーを取ってから編集してください。

3. プレイヤータブ

プレイヤー（player_data）を項目ごとに編集します。主なセクションは次のとおりです。

セクション内容
基本値名前・所持金・現在地など。数値欄には数値を入力します。
説明文(descriptions)外見・背景などの長文。枠の下端をドラッグして高さを変えられます。
キャラクター画像プレイヤーの顔画像と立ち絵。NPC と同じ操作で表示・差し替えができます。詳細。
能力値6 つの能力値。0 を含む入力値はそのまま保持されます（空欄は数値エラーになります）。
身体部位6 部位の状態を表で編集します。
特性(traits)所持している特性の一覧。
スキル(skills) v8所持スキルの一覧。各スキルを専用フォームで編集します。詳細。
インベントリ・装備 v8所持アイテムをグリッド（格子）で配置・編集し、武器・装備品はアイテム ID をプルダウンで指定します。詳細。
生涯ログ(life_log)これまでの出来事の記録。詳細。
エリア履歴(area_history)エリアごとの滞在日数・秩序度・実績などを表（グリッド）で編集します。詳細。
その他（JSON編集）記憶・現在ログなど、構造が複雑な項目は「JSON編集...」ボタンで丸ごと編集します。
タブ最上部の「JSON直接編集」ボタンで、player_data 全体を生の JSON テキストとして編集できます（上級者向け）。v10

4. ワールドタブ

左側のツリーから対象（areas / npcs / quests / story_quests / index など）を選ぶと、右側に編集フォームが表示されます。値は型に応じて自動でウィジェット化されます。

  • 長い文章はリサイズ可能なテキスト枠、配列や複雑な構造は「JSON編集...」ボタンで編集します。
  • ツリー上部の「JSON直接編集」ボタンで、選択中の項目（world_data／index／NPC・エリア等の各レコード）を生の JSON テキストとして丸ごと編集できます。フォームでは直せない壊れたデータの修復にも使えます。v10
  • NPC を選ぶと説明文の下に画像パネル（詳細）、facility（拠点）を選ぶと背景画像（クリックで原寸表示。差し替え不可）が表示されます。
  • ダンジョン（size が dungeon の areas）は dungeon として別ツリーに表示されます（操作は通常の areas と同じ）。
  • npcs / quests / dungeon は所属拠点（area）ごとの見出し（「id: 名前 (件数)」。選択不可）でグループ化されます。拠点不明は「（エリアなし）」、死亡 NPC は「死者」グループへ。
  • NPC の好感度（relationship）は対象ごとに 1 行の表で編集します（詳細）。画像生成プロンプトは look 欄に表示されます。
  • 死亡 NPC（config.is_dead が true）は一覧で名前の横に「（死亡）」と表示されます。
ツリーの右クリックメニュー v10.1
ツリー上で右クリックすると、その項目に対する操作がまとまって表示されます: 新規作成（エリア・NPC・施設・クエスト）／インポート（NPC・施設）／エクスポート（NPC・施設）／JSON直接編集／複製／削除。 右クリックした位置から、新規作成やインポートの配置先（所属エリア・接続先施設）が初期値として引き継がれます。 ボタン列やツールメニューにある同じ機能とまったく同じ動作です。
エリア・施設の削除では、そのツリー上の下位ノード（配下の施設など）もまとめて削除されます。v10.1
未生成 NPC について v9.1
立ち絵画像をまだ取得していない（＝ゲーム内で未生成の可能性がある）NPC も、ほかの NPC と同じくそのまま編集・複製・削除できます。読み取り専用のロックはありません。

5. ゲーム変数タブ

game_variables を編集します。

ここにはバトル中フラグ・会話状態・UI 退避情報など実行時の一時状態が多く含まれます。 不用意な変更はゲーム進行と不整合を起こす可能性があります。仕組みが分からない項目は触らないことをおすすめします。

項目をカテゴリ別の折りたたみグループ（パーティ・進行／戦闘状態／会話・入力状態／UI退避／ログ・テキスト／その他）に分けて表示します。見出しクリックで開閉でき、編集価値の高い「パーティ・進行」だけ既定で開いています。

party（パーティ編成）はメンバーを「ID: 名前」で 1 行ずつ表示し、「削除」で外す／末尾プルダウンと「追加」で加えられます（player は削除不可）。死亡キャラには「（死亡）」が付き、追加時に不整合の警告が出ます。

6. 生涯ログの編集

生涯ログ（life_log）は表（グリッド）で編集します。プレイヤータブと NPC の両方で同じ操作です。

列意味
開始日(day_start)記録の開始日。
終了日(day_end)記録の終了日。
要約回数(summarized_count)要約された回数。
内容(content)本文。セルをダブルクリックすると別ウィンドウで編集できます。
  • 日付・回数の列はセルを直接クリックして書き換えます。
  • 「追加」ボタンで空の行を、「削除」ボタンで選択中の行を削除します。
  • 表の下端のグレーの帯を上下にドラッグすると、表の高さを変えられます。

7. 好感度の編集

NPC の好感度（relationship）は、関係を持つ対象ごとに 1 行の表（グリッド）で編集します。 対象が増えても自動で行が増えます。プレイヤーの行は常に先頭に表示されます。

列意味
対象関係の相手（プレイヤー／NPC 名）。既存の行は固定で変更できません。
好感度(affinity)好感度の数値。
状態(affinity_text)好感度に対応する状態の説明。複数値は「、」で区切ります。
関係(relationship)相手との関係を表すタグ。複数値は「、」で区切ります。
会話回数(conversation_count)会話した回数。
  • 「追加」ボタンで新しい対象の行を、「削除」ボタンで選択中の行を削除します。
  • 新しい対象を追加するときは、対象欄に相手の ID を入力します。
  • 表の下端のグレーの帯を上下にドラッグすると、表の高さを変えられます。

8. エリア履歴の編集

プレイヤータブのエリア履歴（area_history）は、訪れたエリアごとに 1 行の表（グリッド）で編集します。 行の追加・削除はできず、既存エリアの値だけを書き換えます。

列意味
エリア(ID: 名前)対象エリア。areas から名前を解決して表示する参照列です（変更不可）。
滞在日数(total_days)そのエリアでの累計滞在日数。
最終滞在終了(last_stay_end)最後に滞在を終えた日。
秩序度(lawfulness)そのエリアでの秩序度。
実績(achievements)達成した実績の一覧。セルをダブルクリックすると、1 件＝1 行で追加・編集・削除できるダイアログが開きます。
  • 数値の列はセルを直接クリックして書き換えます。
  • 表の下端のグレーの帯を上下にドラッグすると、表の高さを変えられます。

9. インベントリの編集 v8

所持アイテム（inventory）は、ゲームと同じ格子（グリッド）で編集します。 各アイテムは自身の大きさ（width_slots×height_slots）どおりに表示され、設定したアイテム画像も格子上に描画されます。 プレイヤータブと NPC の両方で同じ操作です。

操作説明
ドラッグ＆ドロップアイテムを掴んで別の位置へ移動します。置き先に別アイテムがあると入れ替えになります。
ダブルクリック／編集選んだアイテムを編集ダイアログで開きます（名前・種別・属性・説明・価値・レアリティなど）。
追加新しいアイテム（1×1）を作成します。種別（item_type）を変えると、それに合わせて item_detail・属性・アイテム画像が自動で初期化されます。
削除選択中のアイテムを削除します。
アイテム画像は設定の「ゲーム導入先」（設定）を基準に各アイテムの image_src から解決します。未設定や画像が見つからない場合はグリッド上に「画像パスが未設定」と警告が出ます（編集は可能）。格子の列数・行数も同じ設定で変更できます。
グリッド画面の「エクスポート」「インポート」でアイテムを zip として持ち出し／取り込みできます。プレイヤーのインベントリではツール内の倉庫にも一時保管できます（詳細）。v9

10. アイテムの倉庫・エクスポート／インポート v9

インベントリのアイテムを、ファイル（zip）として持ち出したり、ツール内の倉庫に一時保管したりできます。 操作はすべてインベントリのグリッド画面のボタンから行います。

エクスポート／インポート（ファイル）

アイテムを選んで「エクスポート」を押すと、その 1 アイテムの JSON とアイテム画像が 1 つの zip にまとまって保存されます。 「インポート」では zip を選んで、開いているインベントリ（プレイヤー／NPC）へ新しいアイテムとして追加します。

取り込んだアイテムの ID は自動採番され、格子の空き位置に自動配置されます。 画像はゲーム導入先を基準に元の場所へ復元されます（同じファイルが既にあればそのまま使います）。

倉庫（個別倉庫・共有倉庫） v9

倉庫はツール側の保管箱です。プレイヤーのインベントリでのみ利用でき、画面の右側に 2 つの倉庫グリッドが並びます。

倉庫内容
個別倉庫開いているワールド・キャラクターごとの保管箱です。
共有倉庫全キャラ・全ワールドで共通の保管箱です。別キャラへアイテムを移したいときに使います。
  • アイテムを選び、「個別倉庫へ →」「共有倉庫へ →」でインベントリから倉庫へ保存します。逆向きの「← …から」で倉庫からインベントリへ取り出します。
  • Ctrl＋クリックや、2 つの倉庫グリッド間のドラッグでも振り分けられます。
  • 倉庫の中身は zip としてツールのフォルダ配下に保存され、ツールを閉じても残ります。

11. スキルの編集 v8

スキル（skills）は一覧＋追加／編集／削除で管理します。 一覧のスキルをダブルクリックするか「編集」を押すと、専用フォームが開きます（生 JSON を触らずに編集できます）。 プレイヤータブと NPC の両方で同じ操作です。

項目意味
名前スキル名。
属性(element)属性。既定値とセーブから抽出した実値から選べ、自由入力もできます。
種別(skill_type)物理／魔法などの種別。
最大／現在の使用回数使用回数の上限と残量。
有用度(usefulness)有用度の数値。
説明スキルの説明文。
効果(effects)スキルの効果を一覧で追加・編集・削除します。効果の種別（type）に応じて入力欄が切り替わります。

12. キャラクター画像の編集

ワールドタブで NPC を選んだとき、またはプレイヤータブの「キャラクター画像」セクションで、 顔画像と立ち絵 3 種（縮小色・ピクセル化・原本）が表示されます。どちらも操作は同じです。

操作説明
画像をクリック原寸で別ウィンドウ表示します。
画像取込み（顔画像）任意の画像ファイルを顔画像として取り込みます。
顔画像指定（顔画像）「使用する」立ち絵の上で範囲をドラッグして切り抜き、顔画像にします。
使用する（立ち絵）選んだ立ち絵をゲームが表示する画像に設定します。
取込（外部読み込み） v8任意の画像を外部の立ち絵枠に取り込みます。取込だけではゲームには反映されず、その枠の「使用する」を押すと表示に反映されます。
「使用する」はゲームが読み込む reduced_color_image.png を差し替えます。 元の縮小色画像はバックアップに退避されるので、「立ち絵（縮小色）」の「使用する」を押せば元に戻せます。

13. ワールド生成 v10

ツール → ワールドを生成 から、新しいワールドをまるごと自動生成します。ファイルを開いていなくても使えます。

項目説明
名前ワールド名。空欄なら名前プールからランダムに決まります。
シード生成の乱数シード。同じシード・同じ設定なら同じワールドが再現されます。🎲 ボタンでランダムに振り直せます。
集落数生成する集落の数（既定 9）。
  1. 「生成」を押すと、生成されたワールドが未保存データとしてエディタ本体へ読み込まれ、ワールドタブが開きます（タイトルバーに「（未保存）」と表示されます）。
  2. 内容を確認・編集し、名前を付けて保存（Ctrl+Shift+S）で書き出します（既定のファイル名は world_data.json）。ゲームで遊ぶには worlds\{ワールド名}\world_data.json として配置します。
集落数は 9 を推奨します。ゲーム側は集落 9 個のワールドを前提としており、9 以外にするとゲームがクラッシュして読み込めない恐れがあります（9 以外を指定すると生成前に警告が出ます）。
生成に使う名前プール（ワールド名・エリア名・NPC 名・施設名など）は、exe と同じ場所の namelist フォルダの JSON を書き換えると再ビルドなしでカスタマイズできます（無い・空のキーは内蔵の既定値が使われます）。

14. クエスト作成

ツール → クエスト作成（テンプレから） から開く合成ビルダーです。文章類（タイトル・依頼主名・依頼概要・発言、ダンジョン名・描写・場所）は自由入力でき、各欄の「テンプレ」で保存済みテンプレ（templates/quests/）の値を流用、「テンプレ一括読込」で各欄へまとめて流し込めます。

敵（enemies）・ボス・戦闘イベントは部品ライブラリ（templates/{enemies,bosses,events}）から選んで追加し、各要素は「JSON編集」や専用の編集ダイアログで微調整します。「作成」でダンジョン（area）が生成され、クエストとして選んだ発注拠点に紐付きます。

敵・ボスはその場で新規作成することもできます v10.1。名前・能力・スキル・ドロップなどを構造化フォームで入力して追加でき、作成したものは部品ライブラリにも保存されるので次回以降も選べます。 同じ編集はワールドタブで quests / story_quests を選んだときの enemies / boss / events パネルからも行えます。

部品・文章テンプレはツール → クエストをテンプレ化で既存のワールド／セーブから templates/ へ書き出せます（出力先はダイアログに表示）。
生成されるクエストはテンプレと部品をもとにした素案です。導線（connections）は変更しません。 使用後は必ずゲームで動作を確認してください。

15. NPC のエクスポート／インポート v7

NPC を JSON＋画像をまとめた zip パッケージとして書き出し、別のワールドへ取り込めます。

エクスポート

ワールドタブで NPC を選び、画像パネル付近の「エクスポート」を押します。NPC の JSON と characters/{名前}/ の画像が zip にまとまり、exe と同じ場所の npc\{ワールド名}\ へ保存されます（同名は 名前(2).zip のように自動別名）。

設定の「ワールド毎にフォルダを分けて出力する」をオフにすると、ワールドを区別せず npc\ALL\ へまとめて出力します（設定）。v9

インポート

ツール → NPCをインポート で配置指定ダイアログが開きます。zip を選ぶのではなく、npc\ 配下に書き出し済みの NPC を一覧から選びます。

項目説明
ワールド v9左上のプルダウンで npc\ 配下のワールドを選びます。下の一覧がそのワールドの NPC に切り替わります。前回開いたワールドは次回も自動で選ばれます。
NPC 一覧選んだワールドの NPC が並びます。選ぶと右にプレビュー（顔画像＋要約）が表示されます。
配置先取り込む先の area と拠点（facility）を選びます（ダンジョンは選べません）。
登録先住人（resident）か冒険者（adventurer）かを選びます。area の resident_npcs / adventurer_npcs に登録されます。
名前の重複取り込む NPC の名前が既存と重複する場合の扱い（リネームなど）を指定します。
取り込み時に id は自動採番され、配置先に合わせて current_area / current_location / initial_location が設定されます。 画像は characters/{名前}/ へ展開されます。

16. 施設のエクスポート／インポート v10.1

施設（facility）を facility の JSON＋背景画像をまとめた zip パッケージとして書き出し、別のワールドへ取り込めます。NPC の移植と同じ考え方の、施設版です。

エクスポート

ワールドタブで facility（拠点）を選び、「エクスポート」を押します。あるいはツリーの右クリックメニューからも実行できます。施設の JSON と背景画像が zip にまとまり、exe と同じ場所の facility\{ワールド名}\ へ保存されます。

インポート

ツール → 施設をインポート（またはツリーの右クリック → 施設をインポート）で配置指定ダイアログが開きます。facility\ 配下に書き出し済みの施設を一覧から選びます。

項目説明
ワールドプルダウンで facility\ 配下のワールドを選びます。下の一覧がそのワールドの施設に切り替わります。
施設一覧選んだワールドの施設が並びます（出典・種別を表示）。
配置エリア取り込む先の area を選びます。
接続先（施設）取り込んだ施設をどの既存施設とつなぐかを選びます。
施設名取り込む施設の名前を指定します。
取り込み時、施設の id は自動採番されます。エクスポートでは接続（connections）は保持されず、インポート時に選んだ接続先施設と双方向に張り直されます（owner も初期化）。背景画像は選んだワールドのキャラ／背景フォルダへ展開されます（ワールドフォルダが特定できない場合、背景画像はコピーされません）。

17. プレイヤーを NPC 化 v7

ツール → プレイヤーをNPCに から、プレイヤー（player_data）を NPC オブジェクトへ変換します。 名前・年齢・性格・スキル・インベントリ・画像などはそのまま流用され、能力値は整数へ自動換算されます。

  • 職業・現在地（area／拠点）・HP・口調・弱点などを指定できます。
  • 好感度（relationship）と config は既定値が入り、必要なら「JSON編集」で調整します。
  • 「NPCとして追加」で現在のワールドの npcs に加える／「NPCパッケージとして書き出す」で zip エクスポートできます（インポートと同じ形式）。
リバースエンジニアリングに基づく変換のため、完全な互換は保証されません。 生成後はゲームで動作を確認してください。

18. プレイヤーをプリセット化 v10

ツール → プレイヤーをプリセット化 から、プレイヤー（player_data）を ゲームのキャラ作成画面で選べるキャラクタープリセットに変換して書き出します。 育てたキャラを別のワールドで最初から使いたいときなどに使います。

  • 名前・プロフィール・外見・区分・年齢・スキル・特性はそのまま引き継ぎます（スキルの使用回数は最大値に戻ります）。
  • 能力値は元の値（original_ability_scores）を四捨五入して自動換算します。
  • 性別はセーブに存在しないため、区分（category）の語から自動判別します。
  • 所持金は編集でき、使用ポイント（point_use）は能力値・年齢・スキル・特性・所持金から自動計算されます（ゲーム内で再計算されるため編集不可）。
  • 顔画像・立ち絵などの画像 5 種と prompts.json は、ワールド側のキャラフォルダから複製されます。
出力先は Instantale のデータフォルダ内の characters\{名前}\（saves や worlds と同じ階層）です。 同名のプリセットがある場合は上書き確認が表示されます。
リバースエンジニアリングに基づく変換のため、完全な互換は保証されません。 出力後はゲームのキャラ作成画面で動作を確認してください。

19. ワールドデータのクリーンアップ v9

ツール → ワールドデータをクリーンアップ から、ワールドを「遊び始める前」に近い状態へ一括で戻します。 自分で作ったワールドを配布用に整えるときなどに使います。

  • ストーリークエストの進行状況（config.status）を未完了（incomplete）に戻します。
  • 全 NPC の生涯ログ／現在ログを空にします。
  • 全 NPC の関係（relationship）を初期状態（プレイヤーとの初対面のみ）に戻します。

実行前に確認ダイアログが表示され、処理後は変更件数（ストーリークエスト数・NPC 数）が表示されます。

この操作は元に戻せません（保存するまではファイルには反映されません）。実行前に必ずバックアップを取ってください。

20. quest_event_log の圧縮 v10.1

ツール → quest_event_logを圧縮 から、game_variables の quest_event_log を切り詰めます。 これはゲーム側の既知のバグで、このログが際限なく肥大化しセーブが重くなる問題への緩和策です（ゲーム本体の修正までの一時対応）。

  • quest_event_log は「〈プレイヤーの入力〉」で始まる区切りが連なった 1 本の文字列です。区切り単位（プレイヤーの入力から次の入力の直前まで）を 1 ターンと数え、最新の数ターンだけを残してそれより古い内容を削除します。
  • 実行前に確認ダイアログが表示され、処理後は削除したターン数が表示されます。
この操作は元に戻せません（保存するまではファイルには反映されません）。実行前に必ずバックアップを取ってください。

21. 設定（言語・バックアップ・ウィンドウ・ゲーム導入先） v7

設定メニューから、UI 言語・自動バックアップ・ウィンドウの挙動を変更できます。設定は exe と同じ場所の setting\settings.json に保存されます（v9.2 以前の exe 直下の settings.json は初回起動時に自動で移動します v10）。

言語

UI の表示言語を切り替えます（標準で日本語／英語／簡体字中国語 v10）。選んだ瞬間に画面へ反映されます。 exe 隣の lang フォルダに言語ファイル（<コード>.json）を追加すれば、独自の言語を増やせます。

バックアップ

自動バックアップが ON（既定）のとき、上書き保存の直前に元のファイルを zip で退避します。 保存先は既定でセーブと同じ場所の backups\（変更可）。 ファイル名は {キャラ名}_savedata_日時.zip です。

項目説明
自動バックアップ上書き保存時に旧ファイルを退避するか。
保存先フォルダ空ならセーブと同じ場所の backups\。任意の場所を指定できます。
古い世代の自動削除ON のとき、同じ系列の新しい順に指定件数だけ残し、超過分を削除します（既定オフ）。
内容に変化がない保存ではバックアップは作られません。メニューバー右端で現在 ON/OFF を確認できます。

ゲーム導入先・インベントリ v8

「ゲーム導入先」は、インベントリのアイテム画像（image_src）を解決する基準フォルダです。Instantale をインストールしたフォルダを指定するとグリッドに画像が表示されます（未設定でも編集は可）。「インベントリの列数・行数」で格子の大きさも指定できます。

NPCエクスポート v9

「ワールド毎にフォルダを分けて出力する」が ON（既定）なら npc\{ワールド名}\、OFF なら npc\ALL\ へ出力します（詳細）。

NPC 画像の読み込みスキップ v10.1

「NPC画像を読み込まない」を ON にすると、NPC の顔画像・立ち絵（およびプレイヤーのキャラ画像）を読み込まなくなり、画像欄には「読み込みスキップ中」と表示されます。画像が多いワールドで切り替え・表示の動作を軽くしたいときに使います（画像そのものは削除されません）。

その他（ウィンドウ）

ウィンドウサイズを前回のサイズで起動するか固定サイズで起動するかを選べます。起動位置の記憶も指定できます。

23. 困ったときは

  • 編集が反映されない … 入力欄からフォーカスを外す（別の場所をクリック）と反映されます。最後に「上書き保存」を忘れずに。
  • ゲームがセーブを読み込めなくなった … 自動バックアップ（backups\ 内の zip）または手動コピーから戻してください。
  • タブに「ありません」と出る … そのデータ（プレイヤー／ゲーム変数）を含まないファイルを開いています。異常ではありません。
  • 立ち絵を元に戻したい … NPC の「立ち絵（縮小色）」の「使用する」を押してください。
