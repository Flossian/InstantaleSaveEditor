# Instantale Save Editor（非公式）

**バージョン: v9.1**

ゲーム **Instantale** のセーブデータ／ワールドデータを項目ごとに編集するための非公式デスクトップツールです（C# / WinForms / .NET 8）。データを編集し、ゲームがそのまま読み込める形式で保存します。

> この公開は Instantale の作者様の許諾を得て行っています。作者様より取り下げのご要望があった場合は、速やかに公開を停止します。

## 主な機能

※ プレイヤー／NPC の編集系（インベントリ・スキル・生涯ログ・顔画像／立ち絵）は共通操作です。

- セーブ／ワールドデータの読み込み・編集・保存（ゲームが読める形式で書き戻し）
- プレイヤー編集（基本値・能力値・身体部位・特性・スキル・インベントリ・装備・生涯ログ・エリア履歴・顔画像／立ち絵 など）
- インベントリのグリッド編集（ゲームと同じ格子に配置。ドラッグで移動／入れ替え、追加・編集・削除、画像表示）
- スキルの編集（名前・属性・種別・使用回数・有用度・説明・効果を構造化フォームで編集）
- ワールド編集（areas / npcs / quests / story_quests / index。ダンジョンは別ツリー、npcs / quests / dungeon は拠点ごとにグループ化）
- キャラクター画像（顔画像・立ち絵の表示／差し替え・顔切り抜き・外部画像の取込み）、facility 選択時の背景画像表示
- ゲーム変数の編集（カテゴリ別の折りたたみ表示。party は GUI で追加／削除）
- クエスト作成（テンプレ＋部品ライブラリから合成。ダンジョン追加と連動）と、既存データからの「クエストをテンプレ化」
- NPC のエクスポート／インポート（JSON＋画像を zip 化して別ワールドへ移植。`npc\{ワールド名}\` でワールド別整理）、プレイヤーを NPC 化
- アイテムのエクスポート／インポート（1 アイテムを zip 化して別キャラ・別セーブへ）と、アイテム倉庫（個別倉庫＋共有倉庫の 2 系統。プレイヤーのみ）
- ワールドデータのクリーンアップ（ストーリー進行を未完了に戻し、全 NPC のログ消去・関係を初期化）
- 多言語対応（日本語／英語。`lang` フォルダに JSON 追加で拡張可）、上書き保存時の自動バックアップ（zip 退避・世代自動削除は任意）
- 設定（バックアップ・言語・ウィンドウサイズ・ゲーム導入先・インベントリ格子サイズ・NPC エクスポートのワールド別出力）

## 動作環境
- Windows
- 単体実行ファイル（.NET ランタイム同梱）としてビルド可能

## 使い方（概要）

詳しい操作は [説明書（manual.html）](./manual.html) を参照してください。

1. 「ファイル → 開く」で対象データを選択
2. 各タブ（プレイヤー／ワールド／ゲーム変数）で編集（値はフォーカスが外れた時点で反映）
3. 「ファイル → 上書き保存」で保存（既定で旧ファイルを自動バックアップ）
4. クエスト追加は「ツール → クエスト作成（テンプレから）」から
5. UI 言語の切替・バックアップ・ウィンドウサイズは「設定」メニューから

## 更新履歴

v1〜v6（要約）
- v1: 初版。セーブ／ワールドデータの読み込み・編集・保存
- v2〜v3: 生涯ログのグリッド編集化、顔画像・立ち絵の表示／差し替え、ダンジョンの別ツリー表示、背景画像表示、説明書追加
- v4: 未生成NPCの編集ロック、好感度のグリッド表示化
- v5: エリア履歴のグリッド編集、ゲーム変数のカテゴリ別折りたたみ、party の GUI 編集、死亡キャラ「（死亡）」表示
- v6: クエスト作成の正式機能化、「クエストをテンプレ化」追加、ワールドツリーを拠点ごとにグループ化

v7
- **多言語対応**を追加（日本語／英語の UI 切替。「設定 → 言語」から変更。`lang` フォルダに JSON を置けば言語を追加可能）
- **NPC のエクスポート／インポート**を追加（NPC を JSON＋画像の zip パッケージとして書き出し、別ワールドへ取り込み。配置先の area／拠点・登録先・名前重複の解決を指定）
- **プレイヤーを NPC 化**を追加（`player_data` を NPC オブジェクトに変換して `npcs` へ追加、または zip としてエクスポート。能力値の換算・配置先指定つき）
- **自動バックアップ**を追加（上書き保存の直前に旧ファイルを zip で退避。保存先・世代の自動削除を設定可。既定で ON）
- **設定メニュー**を新設（バックアップ／言語／その他＝ウィンドウサイズの記憶・固定）。設定は exe 隣の `settings.json` にポータブル保存

v8
- **インベントリのグリッド編集**を追加（ゲームと同じ格子にアイテムを大きさ（footprint）どおり配置。**ドラッグ＆ドロップで移動／入れ替え**、**追加・編集・削除**、アイテム画像の表示。プレイヤー／NPC 共通）
- アイテム編集を専用ダイアログ化（種別 `item_type` に応じて `item_detail`・属性・画像を自動初期化。新規作成時にサイズが変更できない問題を修正）
- **スキル編集**を追加（名前・属性・種別・使用回数・有用度・説明・効果(effects) を構造化フォームで編集。生 JSON を触らずに編集可能。プレイヤー／NPC 共通）
- NPC 立ち絵に**外部画像の取込み枠**を追加（任意の画像を取り込み、「使用する」でゲーム表示に反映）
- 設定に**ゲーム導入先**（アイテム画像 `image_src` の解決基準）と**インベントリ格子サイズ**（列数・行数）を追加
- その他、細かい修正とツールの使い勝手を改善

v9
- **アイテムの倉庫機能**を追加（ツール側の保管箱。**キャラ個別倉庫**と全キャラ共通の**共有倉庫**の 2 系統。インベントリと倉庫の間でアイテムを保存／取り出し。Ctrl＋クリックや 2 つの倉庫グリッド間のドラッグで振り分け。プレイヤーのみ）
- **アイテムのエクスポート／インポート**を追加（1 アイテムを JSON＋画像の zip パッケージとして書き出し、別キャラ・別セーブのインベントリへ取り込み。`grid_pos` は空き位置を自動採番）
- **ワールドデータのクリーンアップ**を追加（ツール → ワールドデータをクリーンアップ。ストーリークエストの進行を未完了に戻し、全 NPC の生涯ログ／現在ログを消去・関係を初期状態に戻す。確認ダイアログ付き）
- **NPC のエクスポート／インポートを改修**（出力先・取込元を `npc\{ワールド名}\` でワールド別に整理。インポート画面に**ワールド選択プルダウン**を追加し、前回開いたワールドを記憶。設定で「ワールド毎にフォルダを分けて出力する」を切替可能）
- **ツリー更新機能**を追加（NPC インポート等の後にワールドタブのツリーを再構築）。**別 NPC を開くと編集内容が破棄される不具合**を修正
- その他、細かい修正

- 上記の修正に伴い、v4 で導入した**未生成 NPC の編集ロックを廃止**
