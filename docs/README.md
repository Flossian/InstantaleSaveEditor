# Instantale Save Editor（非公式）

**バージョン: v7**

ゲーム **Instantale** のセーブデータ／ワールドデータを項目ごとに編集するための非公式デスクトップツールです（C# / WinForms / .NET 8）。データを編集し、ゲームがそのまま読み込める形式で保存します。

## 主な機能
- セーブ／ワールドデータの読み込み・編集・保存（ゲームが読める形式で書き戻し）
- プレイヤー編集（基本値・能力値・身体部位・特性・インベントリ・装備・生涯ログ・顔画像／立ち絵 など）
- ワールド編集（areas / npcs / quests / story_quests / world_data / index。ダンジョンは別ツリーで表示。npcs / quests / dungeon は拠点ごとにグループ化）
- キャラクターの顔画像・立ち絵の表示と差し替え（画像取込み・顔切り抜き・立ち絵の切替。プレイヤー／NPC 共通）
- facility（拠点）選択時の背景画像の表示
- 生涯ログ(life_log)のグリッド編集（プレイヤー／NPC 共通）
- エリア履歴(area_history)のグリッド編集（プレイヤー）
- ゲーム変数の編集（カテゴリ別の折りたたみ表示。party はメンバーを GUI で追加／削除）
- テンプレートを組み合わせたクエスト作成（ダンジョン追加と連動。敵・ボス・イベントは部品ライブラリから選択）
- 既存データからクエストテンプレと部品（敵・ボス・イベント）を抽出する「クエストをテンプレ化」
- NPC のエクスポート／インポート（JSON＋画像を zip パッケージ化して別ワールドへ移植）
- プレイヤーを NPC 化（player_data を NPC に変換して npcs へ追加、または zip エクスポート）
- 多言語対応（日本語／英語。設定→言語で切替。`lang` フォルダに JSON を置けば言語を追加可能）
- 上書き保存時の自動バックアップ（旧ファイルを zip で退避。世代の自動削除も任意で設定可）
- 設定（バックアップ・言語・ウィンドウサイズの記憶／固定）

## 動作環境
- Windows
- 単体実行ファイル（.NET ランタイム同梱）としてビルド可能

## 使い方（概要）

詳しい操作は [説明書（manual.html）](./manual.html) を参照してください。

1. 「ファイル → 開く」で対象データを選択
2. 各タブ（プレイヤー／ワールド／ゲーム変数）で編集（値はフォーカスが外れた時点で反映）
3. 「ファイル → 上書き保存」で保存（既定で旧ファイルを自動バックアップ）
4. クエスト追加は「ツール → クエスト作成（テンプレから）」から
5. UI 言語の切替・バックアップ・ウィンドウサイズは「設定」メニューから

## 更新履歴

v1
- 初版公開
- セーブ／ワールドデータの読み込み・編集・保存（ゲームが読める形式で書き戻し）
- プレイヤー／ワールド／ゲーム変数の編集

v2
- 生涯ログ(life_log)を**グリッド編集**化（プレイヤー／NPC 共通）
- NPC の**顔画像・立ち絵の表示と差し替え**機能を追加（画像取込み・顔切り抜き・立ち絵の切替）
- 説明書（manual.html）を追加
- 各種バグ修正

v3
- プレイヤータブに**キャラクター画像**セクションを追加（顔画像・立ち絵の表示／差し替え。NPC と共通操作）
- ワールドタブで**ダンジョン**（`size` が `dungeon` の areas）を別ツリーに分離して表示
- facility（拠点）選択時に**背景画像**を表示（クリックで原寸表示）

v4
- 未生成NPCの編集ロック機能を追加(立ち絵が生成されているかで判断)
- NPCの好感度表示を分かりやすい形(Grid形式)に変更
- NPCの画像生成プロンプトの表示する欄を移動、見やすい形に変更

v5
- プレイヤータブに**エリア履歴(area_history)のグリッド編集**を追加（滞在日数・秩序度などを表で編集、実績はダイアログで編集）
- ゲーム変数タブを**カテゴリ別の折りたたみ表示**に変更（「パーティ・進行」だけ既定で展開）
- **party（パーティ編成）をGUIで編集**（メンバーの追加／削除。死亡キャラの追加は警告）
- ワールドタブの NPC 一覧で、**死亡キャラに「（死亡）」表示**を追加
- 「開く」ダイアログの初期フォルダがセーブ保存先を正しく開くよう修正

v6
- **クエスト作成（テンプレから）を正式機能化**（v5まで「作成中」で無効）。文章は自由入力＋各欄「テンプレ」ボタン、敵・ボス・イベントは部品ライブラリから選択して追加し、JSON 編集で微調整。「作成」でダンジョン area とクエストを生成して発注拠点に紐付け
- **「クエストをテンプレ化」**を追加（既存の world_data / savedata からクエストテンプレと部品（敵・ボス・イベント）を `templates/` 配下へ書き出す）
- ワールドタブのツリーを**拠点（area）ごとにグループ化**（dungeon / npcs / quests を所属拠点の見出しでまとめて表示。死亡 NPC は「死者」グループに集約）
- 内部リファクタ（グリッド系コントロールの共通基底化など）

v7
- **多言語対応**を追加（日本語／英語の UI 切替。「設定 → 言語」から変更。`lang` フォルダに JSON を置けば言語を追加可能）
- **NPC のエクスポート／インポート**を追加（NPC を JSON＋画像の zip パッケージとして書き出し、別ワールドへ取り込み。配置先の area／拠点・登録先・名前重複の解決を指定）
- **プレイヤーを NPC 化**を追加（`player_data` を NPC オブジェクトに変換して `npcs` へ追加、または zip としてエクスポート。能力値の換算・配置先指定つき）
- **自動バックアップ**を追加（上書き保存の直前に旧ファイルを zip で退避。保存先・世代の自動削除を設定可。既定で ON）
- **設定メニュー**を新設（バックアップ／言語／その他＝ウィンドウサイズの記憶・固定）。設定は exe 隣の `settings.json` にポータブル保存
